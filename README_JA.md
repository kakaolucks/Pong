# Console Pong

C++17とネイティブWindows APIを使用して構築された、コンソール風のオンラインPongゲームです。

コンソール風の外観ですが、これは**コンソールアプリケーションではありません**。グラフィカルなゲームウィンドウを持つ、ネイティブWin32 GUIアプリケーションとして動作します。

## 特徴

* コンソール風のターミナルインターフェース
* ネイティブWin32 GUI
* TCPによるオンラインマルチプレイヤー
* ホスト（Host）および参加（Join）モード
* ホスト側主導のゲームシミュレーション
* 滑らかな60 FPSのゲームプレイ
* 5分間の試合時間
* 11点先取で勝利
* 試合中にボールの速度が徐々に上昇
* 複数のゲームプレイ用アイテムと一時的な効果
* 画面回転エフェクト
* 巻き戻しエフェクト
* 再戦システム
* キーボード操作
* 接続およびエラー処理

## ゲームモード

### ホスト (Host)

ホストはゲームを作成し、TCP接続の待機（リッスン）を行います。

ホストは左側のパドルを操作します。

### 参加 (Join)

2人目のプレイヤーは、IPアドレスまたはホスト名とポート番号を使用してホストに接続します。

参加するプレイヤーは右側のパドルを操作します。

専用サーバーは必要ありません。ホスト側のプロセスが、ゲームをプレイしつつ、ゲームの主導権を握るサーバーとしての役割も果たします。

## 操作方法

| キー                         | アクション                 |
| ---------------------------- | -------------------------- |
| `W` / `A`                    | パドルを上に移動           |
| `S` / `D`                    | パドルを下に移動           |
| `↑` / `←`                   | パドルを上に移動           |
| `↓` / `→`                   | パドルを下に移動           |
| `Enter`                      | 準備完了 / 続行 / 再戦     |
| `ESC`                        | キャンセル / 戻る / 中止   |

メニュー操作は以下のキーでも行えます：

```text
1 - ホスト (Host)
2 - 参加 (Join)
3 - 終了 (Quit)

```

## 試合ルール

試合時間は最大5分間です。

試合は以下のいずれかで終了します：

* プレイヤーのどちらかが11点に達したとき、または
* 5分間のタイマーが終了したとき。

タイマーが終了した場合、スコアが高いプレイヤーの勝利となります。引き分けになることもあります。

得点後、次のサーブの前に短いインターバル（ポイント間の休憩）があります。

続行するには、両プレイヤーが `Enter` キーを押す必要があります。試合終了後、両プレイヤーは15秒以内に再戦（リマッチ）の投票を行うことができます。

双方が同意した場合、既存の接続を維持したまま次のラウンドが開始されます。

## アイテム

プレイ中、フィールド上にランダムなアイテムが出現します。

### スピードアップ (Speed Up)

ボールの速度を一時的に上げます。

効果時間：5秒

### リワインド (Rewind)

ゲームの状態を最大で約5秒前まで巻き戻します。

この効果を実現するため、ゲームは過去数秒間の状態を記録しています。

### バウンス (Bounce)

ボールの水平方向の動きを反転させます。

### パドルスピード (Paddle Speed)

最後にボールを打ったプレイヤーのパドル速度を一時的に上げます。

効果時間：10秒

### リバース (Reverse)

最後にボールを打ったプレイヤーの操作を一時的に反転させます。

効果時間：10秒

### 回転 (Rotate)

ゲーム画面を一時的に回転させます。

回転時にはアニメーションによる遷移が行われ、ゲームフィールドのレイアウトが縦長（ポートレート）に変わります。

効果時間：30秒

## ボールの速度

試合の進行に伴い、ボールの速度は徐々に上がっていきます。

時間経過による速度上昇は、初期速度の最大3倍まで達します。

また、パドルでボールを打ち返すたびに、ボールの速度はわずかに上昇します。

得点が入ると、次のサーブに向けてボールの速度はリセットされます。

## ネットワーク

本ゲームはWinsock2を使用したTCP通信を利用します。

ホスト側の動作：

1. TCPリスニングソケットを作成します。
2. プレイヤーからの接続を待ち受けます。
3. 権威ある（マスターとなる）ゲームシミュレーションを実行します。
4. ゲーム状態の更新情報をクライアントに送信します。

クライアント側の動作：

1. ホストに接続します。
2. プレイヤーの入力を送信します。
3. 権威あるゲーム状態の更新情報を受信します。

不要なネットワーク遅延を抑えるため、`TCP_NODELAY`が有効になっています。

一度にホストへ接続できるクライアントは1台のみです。

## インターネット経由でのプレイ

異なるネットワーク上のプレイヤーと対戦する場合、ホスト側でWindowsファイアウォールの設定を変更して指定ポートを許可したり、ルーターでポート転送（ポート開放）の設定を行ったりする必要がある場合があります。

デフォルトのポート番号は以下の通りです：

```text
5000
```

接続時、クライアントはホストのIPアドレスまたはホスト名と、同じポート番号を必要とします。

LAN内でのプレイでは、ホストのローカルIPアドレスを使用できます。 ## インターフェース

本作は、コンソール（端末）を彷彿とさせる以下のインターフェースを採用しています。

*   黒い背景
*   緑色のターミナル風テキスト
*   Consolasフォント
*   テキストベースのメニュー
*   キーボード操作によるナビゲーション

実際のゲーム画面には、パドルやボールが滑らかに動くグラフィカルなWin32レンダリング領域が使用されています。

デフォルトのゲームウィンドウサイズは以下の通りです。

```text
960 x 540
```

### アーキテクチャ

本プロジェクトは、`WinMain` を使用したネイティブWindows実行ファイルとして実装されています。

ホストは以下の両方の役割を担います。

*   ゲームサーバー
*   ローカルゲームクライアント

クライアントは、ゲームの状態全体を独自にシミュレートするのではなく、ホストから「正」となる状態（オーソリテイティブな状態）を受け取ります。

## ビルド

### MinGW / GCC

ソースファイルは以下のコマンドでコンパイル可能です。

```bash
g++ -O2 -std=c++17 -mwindows -o pong.exe pong.cpp -lgdi32 -luser32 -lws2_32
```

`-mwindows` オプションの指定が重要です。これは、アプリケーションがコンソール用の `main()` エントリポイントではなく、Windows GUI サブシステムと `WinMain` を使用しているためです。

MinGW の環境によっては、GDI+ を明示的にリンクする必要がある場合もあります。

```bash
-lgdiplus
```

例:

```bash
g++ -O2 -std=c++17 -mwindows -o pong.exe pong.cpp -lgdi32 -lgdiplus -luser32 -lws2_32
```

## 備考

このプロジェクトは、内部的にはネイティブな Windows GUI ウィンドウを使用しつつ、見た目や操作感は昔ながらのコンソールアプリケーションのように感じられるよう設​​計されています。

そのため、これは **Windows コンソールアプリケーションではなく、Win32 GUI アプリケーション** となります。

コンソール風のインターフェースはあくまでゲームのビジュアルデザインの一部であり、アプリケーションの基盤となるサブシステムがコンソール用であるわけではありません。
